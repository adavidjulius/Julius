# Remaining Limitations & Areas for Improvement

| Subsystem | Current Limitation | Recommended Architecture Improvement | Status |
| :--- | :--- | :--- | :--- |
| **Web Scraping vs Official APIs** | Web scraping providers (ChatGPT, Grok, Kimi, Gemini) remain susceptible to frontend DOM class changes and Cloudflare Turnstile challenges. | Recommend prioritizing official Cloud API keys (`GROK_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`, `KIMI_API_KEY`) configured in `.env`, which Julius automatically routes via high-speed SSE streaming. | *Documented / Optional user configuration* |
| **Multi-line Composer Geometry** | In terminals with very small vertical dimensions (< 15 rows), multi-line expansion of the Composer can crowd out the conversation history. | Implement an auto-clamping rule in `Composer.tsx` and `composer.py`: when terminal rows are below 18, cap input height strictly at 2 lines. | **RESOLVED**: Auto-clamping rule active in `Composer.tsx` (React Ink) and `composer.py` (Textual) capping input height at 2 lines on small terminals (`rows < 18`). |
| **Workspace Token Flooding** | Running broad directory listings (`list_dir` or `find`) in large repositories (e.g. monorepos with nested `node_modules` or `dist`) can consume excessive context. | Leverage `.geminiignore` filters inside `ActionExecutor.list_dir` and `search_files` to prevent non-source build artifacts from ever reaching the observation prompt. | **RESOLVED**: Loaded `.geminiignore` / `.gitignore` rules and built-in noise ignore patterns in `ActionExecutor.list_directory` and `search_files`, preventing token flooding from `node_modules`, `dist`, `.venv`, `.pytest_cache`, and build caches. |
| **Session Cookie Preservation** | If Chromium locks fail to release on forced process termination (`kill -9`), stale lockfiles (`SingletonLock`) can occasionally trigger browser startup delays. | Add a pre-launch sweep in `llm_web_client.py` to remove stale `SingletonSocket` symlinks before spawning Chromium. | **RESOLVED**: Added pre-launch multi-directory sweep in `llm_web_client.py` checking `is_symlink() or exists()`, purging dangling `SingletonSocket` symlinks and temporary socket endpoints across profile directories before Chromium spawn. |
